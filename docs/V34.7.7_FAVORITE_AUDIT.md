# V34.7.7 ENIKK 애장품 21명 전수 감사 및 계산 반영

## 완료 기준

V34.7.7은 폴리·슈가·라플라스 3명만 구현한 패치가 아니다. ENIKK가 배포한 SSR Favorite 마스터 21개를 기준으로 전원을 등록하고, 일반 상태(Phase 0)와 Phase 1~3을 분리 계산한다. 3명은 수치 심층 회귀의 대표 표본일 뿐이며, 전체 21명은 TID·단계 순서·스킬 레벨 유지·계산 결과 변화를 자동 검증한다.

## 감사 범위

- ENIKK 배포 Next.js 청크 49개 전수 확인, 수집 실패 0건
- SSR Favorite 마스터 TID 21개 전부 캐릭터 자원 ID로 결합
- 캐릭터 21명의 일반 무기 수치와 스킬 1·2·버스트 Lv.1~10 전부 확보
- 애장품 Phase 1~3 카드 63개와 변형 슬롯 순서 전부 확보
- `favoriteItemTid`, `favoriteItemLv`, `skill1Lv`, `skill2Lv`, `ultiSkillLv` 소비 경로 확인

## 권위 규칙

1. 외부 동기화의 캐릭터 애장품 식별은 **TID 우선**이다. `nameCode`는 동일 캐릭터의 Phase 0 정규 프로필 선택과 비애장품 보조 식별에 사용한다.
2. 유효한 SSR Favorite TID가 없으면 Phase 0이다.
3. `favoriteItemLv` 0/1/2 이상은 Phase 1/2/3으로 변환한다.
4. 스킬 레벨은 애장품 단계와 독립적으로 유지한다. `skill1Lv → skill1`, `skill2Lv → skill2`, `ultiSkillLv → burst`이며 1~10 범위 외의 강제 상향을 하지 않는다.
5. 각 Phase는 해당 슬롯만 일반 카드에서 애장품 카드로 교체하고, 아직 해금되지 않은 슬롯은 일반 카드를 유지한다.

## 수정한 실제 오류

- 일반 캐릭터와 애장품 캐릭터 행을 합칠 때 `Math.max(..., 3)`으로 Phase 3을 강제하던 경로 제거
- 스킬 레벨을 `Math.max(..., 4)`로 올리던 경로 제거
- TID보다 `nameCode`를 먼저 사용해 바이퍼 `200501`을 슈가로 오인할 수 있던 경로 제거
- 바이퍼 TID `200501`, 슈가 TID `202101`을 영구 회귀 항목으로 고정
- 기존 정밀 타임라인에서 모든 B2 쿨타임을 20초로 고정하던 경로를 프로필별 20/40초 소비로 교체
- 정밀·자동 최적화·공통 성장 컨텍스트에 `favoriteItemPhase` 전달
- 기존 14개 애장품 ID를 갱신하고, 누락됐던 디젤·엑시아·프림·바이퍼·밀크·율리아·베이 7개 전용 계산 프로필 추가
